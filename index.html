Connect Instagram & Facebook

  1. Open developers.facebook.com/tools/explorer and pick your app (Advon Media Posts).
  2. Under «User or Page» choose Get User Access Token and tick: pages_show_list, pages_read_engagement, pages_manage_posts, instagram_basic, instagram_content_publish, business_management.
  3. Press Generate Access Token, allow the Advon Media page, copy the token and paste it below.
  4. App ID and App Secret are in the app's Settings → Basic. With them the connection never expires.
The app secret is used once to make the token permanent and is not kept. The token is stored encrypted.

Sync setup

Cross-device sync needs one value stored on the server. This is not your passphrase and cannot be turned back into it — it is a one-way fingerprint.

Your CRM_AUTH_HASH:

—

In Netlify → your site → Site configuration → Environment variables, add:

  1. CRM_AUTH_HASH — the value above
  2. CRM_GH_REPO — the private data repo, e.g. agelmet/advon-crm-data
  3. CRM_GH_TOKEN — a GitHub token with Contents read & write on that repo

Then redeploy the site. Full instructions are in README-SYNC.md in the website repo.
